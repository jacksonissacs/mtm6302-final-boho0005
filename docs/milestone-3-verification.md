# Prototype verification

The source passes JavaScript syntax checks. Browser results and screenshots are produced by the repository’s Chrome review of a local HTTP server. The review record is updated after inspection. The final storage cases in the Milestone 2 acceptance plan remain planned.

Run the app with `python3 -m http.server 8000` in the repository root. Open http://127.0.0.1:8000/ and use **Explore example spots** for an isolated populated session. The review workflow runs the same site using [the browser checks](../qa/browser.cjs).
